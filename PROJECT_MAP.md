## Source authority and publication boundary

The current architecture separates private operational authority from public publication:

| Layer | Current role |
|---|---|
| SSD / local repositories | Private source authority and operational work |
| GitHub repositories | Public surface only |
| `*-Showcase` repositories | Independent sanitized public representations of selected private/local projects |
| `proftectiagocosta-hash` | Public map and ecosystem entrypoint |

There are **no private GitHub mirrors in the current architecture**.

This public map intentionally does not enumerate the private/local source tree. That boundary reduces accidental disclosure and keeps the profile focused on material that is intended to be public.

A public showcase is not assumed to be a fork, byte-for-byte mirror, deployment surface, or automatic publication of its private/local source project.
