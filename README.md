## Public / Private Boundary

The current architecture is explicit:

- **SSD / local repositories:** private source authority and operational work.
- **GitHub:** public surface only.
- **Public showcases:** independent sanitized representations of selected private/local projects.
- **No private GitHub mirrors are part of the current architecture.**

This profile intentionally does not enumerate the private source tree. Public repositories are designed to be safe to inspect and share without exposing private source, credentials, personal data, operational checkpoints, or internal execution material.

Pinned repositories are managed manually in the GitHub UI and are **not asserted here as a currently verified set**.
